Idea clave

4 → 3

Se reduce el tamaño real del arreglo tras mover cada posición.

Código modificado

void eliminarYDesplazarDerecha(int pos) {
  if (pos < 0 || pos >= tope) return;
  for (int i = pos; i < tope - 1; i++) {
    arr[i] = arr[i + 1];
  }
  arr[tope - 1] = 0;
  tope--;
}
