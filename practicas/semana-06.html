1 ¿Qué hace?

Muestra la información del alumno ubicado en el tope sin extraerlo de la estructura.

2 Código del método
public void consultarCima() {
    if (estaVacia()) {
        System.out.println("La pila está vacía.\nNo hay elementos en la cima.");
        return;
    }
    System.out.println("\n--- INFORMACIÓN DE LA CIMA ---");
    System.out.println(arregloPila[top]);
    System.out.println("------------------------------");
}
3 Paso a paso

1. Verifica

Se llama al método estaVacia(). Si la pila no tiene elementos, se muestra un mensaje y termina el método.

Pila vacía
La pila está vacía.
No hay elementos en la cima.

2. Accede al tope

Si la pila tiene elementos, se accede directamente al índice top del arreglo para obtener el alumno que está en la cima.

A B C D
top → Alumno 3

3. Imprime

Finalmente, se imprime la información del alumno en la cima y se muestra un separador.
