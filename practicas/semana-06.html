Código del método
public void buscarAlumnoPorCodigo(String codigo) {
    if (estaVacia()) {
        System.out.println("La pila está vacía. No se puede realizar la búsqueda.");
        return;
    }
    boolean encontrado = false;
    for (int i = top; i >= 0; i--) {
        if (arregloPila[i].getCodigo().equals(codigo)) {
            System.out.println("Alumno encontrado");
            System.out.println("Datos: " + arregloPila[i]);
            encontrado = true;
            break;
        }
    }
    if (!encontrado) {
        System.out.println("No se encontró ningún alumno con el código: " + codigo);
    }
}

Se usa un ciclo para recorrer la pila desde el tope hasta la base y comparar códigos.

3.3 Compara

Si encuentra coincidencia, imprime los datos del alumno y marca la variable encontrado.

3.4 Final

Si no existe, muestra el mensaje de que no se encontró ningún registro con ese código.

Explicación del código

3.1

Como el índice top comienza en -1, la cantidad de elementos actuales se obtiene con:

elementosActuales = top + 1

3.2

Se resta la cantidad de elementos actuales a la capacidad total para obtener los espacios libres:

espaciosLibres = capacidad - elementosActuales

3.3

Finalmente, se imprime el mensaje con los tres datos: capacidad total, elementos almacenados y espacios libres.
