buscarAlumnoPorCodigo(String codigo)

☕
Recorre la pila para ubicar un alumno específico mediante su código, indicando si existe y su posición relativa respecto a la cima.
1 ¿Qué hace?
  • Busca un alumno en la pila usando su código.
  • Si existe, muestra sus datos.
  • Si no existe, informa que no se encontró.
2 Código del método
public void buscarAlumnoPorCodigo(String codigo) {
    if (estaVacia()) {
        System.out.println("La pila está vacía. No se puede realizar la búsqueda.");
        return;
    }
    boolean encontrado = false;
    for (int i = top; i >= 0; i--) {
        if (arregloPila[i].getCodigo().equals(codigo)) {
            System.out.println("Alumno encontrado");
            System.out.println("Datos: " + arregloPila[i]);
            encontrado = true;
            break;
        }
    }
    if (!encontrado) {
        System.out.println("No se encontró ningún alumno con el código: " + codigo);
    }
}
3 Paso a paso

3.1

Si la pila está vacía, se muestra un mensaje y termina la búsqueda.

La pila está vacía.

3.2

Se usa un ciclo para recorrer la pila desde el tope hasta la base y comparar códigos.

Se recorre la pila desde la cima.

3.3

Si encuentra coincidencia, imprime sus datos y termina la búsqueda.

Alumno encontrado.

mostrarEstadoCapacidad()

☕
Calcula y muestra el total de la capacidad, los elementos actuales almacenados y los espacios libres disponibles en la pila.
1 ¿Qué hace?
  • Calcula y muestra el total de la capacidad.
  • Indica los elementos actuales almacenados.
  • Determina los espacios libres disponibles.
2 Código del método
public void mostrarEstadoCapacidad() {
    int elementosActuales = top + 1;
    int espaciosLibres = capacidad - elementosActuales;
    System.out.println("--- ESTADO DE CAPACIDAD DE LA PILA ---");
    System.out.println("Capacidad máxima total: " + capacidad);
    System.out.println("Elementos almacenados: " + elementosActuales);
    System.out.println("Espacios libres: " + espaciosLibres);
}
3 Explicación del código

3.1

Como el índice top comienza en -1, la cantidad de elementos actuales se obtiene con:

elementosActuales = top + 1

3.2

Se resta la cantidad de elementos actuales a la capacidad total para obtener los espacios libres:

espaciosLibres = capacidad - elementosActuales

3.3

Finalmente, se imprime el mensaje con los tres datos: capacidad total, elementos almacenados y espacios libres.

mostrarMejorPromedio()

☕
Analiza los elementos de la pila y determina cuál estudiante tiene el mejor promedio académico.
¿Qué hace?
  • Analiza los elementos en la pila.
  • Determina cuál estudiante tiene el mejor promedio.
  • Lo muestra en pantalla.
Código del método
public void mostrarMejorPromedio() {
    if (estaVacia()) {
        System.out.println("La pila está vacía.");
        return;
    }
    float mejorAlumno = 0;
    for (int i = 0; i <= top; i++) {
        if (arregloPila[i].getPromedio() > mejorAlumno) {
            mejorAlumno = arregloPila[i].getPromedio();
        }
    }
    System.out.println("El mejor promedio es: " + mejorAlumno);
}
