consultarCima()

Java
1

¿Qué hace?

Muestra la información del alumno ubicado en el tope sin extraerlo de la estructura. 

public void consultarCima() {
    if (estaVacia()) {
        System.out.println("La pila está vacía.
        No hay elementos en la cima.");
        return;
    }
    System.out.println("--- INFORMACIÓN DE LA CIMA ---");
    System.out.println(arregloPila[tope]);
    System.out.println("-------------------------------");
}
Paso a pasoExplicación del código
1

Verifica si la pila está vacía

Se llama al método estaVacia(). Si la pila no tiene elementos, se muestra un mensaje y se termina.

Pila vacía
2

Accede al tope de la pila

Si la pila tiene elementos, se accede directamente al índice tope del arreglo para obtener el alumno que está en la cima.

3

Imprime los datos

Finalmente, se imprime la información del alumno en la cima y se muestra un separador.

--- INFORMACIÓN DE LA CIMA ---
En resumen
consultarCima() verifica si la pila está vacía y, si tiene elementos, accede al índice tope del arreglo para mostrar sus datos sin extraerlos.

buscarAlumnoPorCodigo(String codigo)

Java
1

¿Qué hace?

  • Busca un alumno en la pila usando su código y muestra si existe o no.
  • Sus datos.
  • La posición relativa respecto a la cima (0 = cima).
public void buscarAlumnoPorCodigo(String codigo) {
    if (estaVacia()) {
        System.out.println("La pila está vacía. No se puede realizar la búsqueda.");
        return;
    }

    boolean encontrado = false;
    for (int i = tope; i >= 0; i--) {
        if (arregloPila[i].getCodigo().equals(codigo)) {
            System.out.println("\nAlumno encontrado!");
            System.out.println("Datos: " + arregloPila[i]);
            System.out.println("Posición relativa con la cima: " + (tope - i));
            encontrado = true;
            break;
        }
    }

    if (!encontrado) {
        System.out.println("\nNo se encontró ningún alumno con el código: " + codigo);
    }
}
Paso a pasoExplicación del código
3.1

Verifica si la pila está vacía

Si la pila está vacía, se muestra un mensaje de advertencia y se termina el método.

Si está vacía, no se puede realizar la búsqueda.
3.2

Recorre la pila desde la cima

Se usa un ciclo que va desde el índice tope hasta 0, en orden descendente.

3.3

Compara el código

Si el código coincide con el de un alumno, se imprime su información y la posición relativa respecto a la cima.

3.4

Si no lo encuentra

Se termina el recorrido sin encontrarlo y se muestra un mensaje de que no existe.

No se encontró ningún alumno con el código.

Ejemplo práctico (alumno encontrado)

Cima (tope = 3) → A005 (pos 0)
A004 (pos 1)
A003 (pos 2)
A002 (pos 3)
Buscar alumno por código "A003" → Alumno encontrado
Datos: Alumno{codigo='A003', nombre='Ana Pérez', ...}
Posición relativa respecto a la cima: 2

Ejemplo práctico (no encontrado)

Cima (tope = 2) → A005 (pos 0)
A002 (pos 1)
A001 (pos 2)
BuscarAlumnoPorCodigo("A010")
→ No se encontró ningún alumno con el código A010
En resumen
buscarAlumnoPorCodigo(String codigo) recorre la pila desde la cima, compara los códigos y, si encuentra al alumno, muestra sus datos y la posición relativa. Si no lo encuentra, indica que no existe.

mostrarEstadoCapacidad()

Java
1

¿Qué hace?

  • Calcula y muestra el total de la capacidad, los elementos actuales almacenados y los espacios libres disponibles.
public void mostrarEstadoCapacidad() {
    int elementosActuales = tope + 1;
    int espaciosLibres = capacidad - elementosActuales;
    System.out.println("--- ESTADO DE CAPACIDAD DE LA PILA ---");
    System.out.println("Capacidad máxima total: " + capacidad);
    System.out.println("Elementos almacenados: " + elementosActuales);
    System.out.println("Espacios libres: " + espaciosLibres);
    System.out.println("--------------------------------------");
}
Explicación del código
3.1

Cálculo de elementos actuales

Como el índice tope comienza en -1, la cantidad de elementos actuales se obtiene con:

elementosActuales = tope + 1
3.2

Cálculo de espacios libres

Se resta la cantidad de elementos actuales a la capacidad total:

espaciosLibres = capacidad - elementosActuales
3.3

Mostrar la información

Finalmente, imprime en consola los tres datos: capacidad total, elementos almacenados y espacios libres.

Ejemplo práctico

capacidad = 5
tope = 2
Cálculos:
elementosActuales = 2 + 1 = 3
espaciosLibres = 5 - 3 = 2
Salida en consola:
--- ESTADO DE CAPACIDAD DE LA PILA ---
Capacidad máxima total: 5
Elementos almacenados: 3
Espacios libres: 2
En resumen
mostrarEstadoCapacidad() calcula los valores con tope + 1 y capacidad - elementosActuales, y luego los muestra para conocer el estado de la pila.

mostrarMejorPromedio()

Java
5

¿Qué hace?

Analiza los elementos en la pila y determina cuál estudiante posee el mejor promedio académico.

public void mostrarMejorPromedio() {
    if (estaVacia()) {
        System.out.println("La pila está vacía.");
        return;
    }

    Alumno mejorAlumno = arregloPila[0];
    for (int i = 1; i <= tope; i++) {
        if (arregloPila[i].getPromedio() > mejorAlumno.getPromedio()) {
            mejorAlumno = arregloPila[i];
        }
    }

    System.out.println("--- MEJOR PROMEDIO ---");
    System.out.println("Alumno: " + mejorAlumno.getNombre());
    System.out.println("Promedio: " + mejorAlumno.getPromedio());
}
--- MEJOR PROMEDIO ---
Alumno: Ana García
Promedio: 9.8
